Mesh mathematics

The geometry and topology algorithms behind mesh validation, face extraction, boundary detection and quality diagnostics.

1. Geometric representation

A node is a point x = (x,y,z) in Euclidean three-space. An element is a finite set of nodes plus a reference topology and an ordered connectivity. Coordinates use binary64 in MeshData. The ordering matters: it defines the element's local coordinate map and orientation, not merely its membership.

2. Bounding box and scale-aware tolerances

For coordinates xi, the axis-aligned bounding box has componentwise extrema xmin, xmax. Its diagonal is

L = ‖xmax − xmin‖₂ = √(Δx² + Δy² + Δz²).

The validator combines an absolute tolerance and a relative tolerance scaled by the model size:

εL = max(εabs, εrel L),   εA = εL²,   ε6V = 6 εL³.

This dimensional scaling avoids applying one fixed length threshold to both microscopic and large models. The thresholds are numerical safeguards, not manufacturing tolerances or a guarantee of mesh accuracy.

3. Triangle geometry

For triangle vertices a, b, c, the area is half the norm of the cross product:

A = ½ ‖(b − a) × (c − a)‖.

A triangle is degenerate when its area or one of its edge lengths is below the corresponding tolerance. Interior angles are evaluated using the cosine law, with the cosine clamped to [−1,1] to protect acos from round-off excursions:

cos θa = ((b−a)·(c−a)) / (‖b−a‖ ‖c−a‖).

The minimum angle is a useful shape diagnostic: very small angles indicate a sliver-like triangle and often lead to poor interpolation conditioning. It is not by itself a complete surface quality metric.

4. Tetrahedron orientation and volume

For a linear tetrahedron with vertices x0 … x3, form the edge matrix

J = [x₁−x₀   x₂−x₀   x₃−x₀].

The signed six-volume is det(J), so the signed volume is V = det(J)/6. A zero determinant means a degenerate tetrahedron; a negative determinant means its node ordering has the opposite orientation from the convention expected by the validator. The sign is meaningful only relative to the chosen local ordering.

OpenModel's tetrahedron mean-ratio quality is normalized so that a regular tetrahedron has value 1 and a degenerate tetrahedron approaches 0. The implementation compares a configurable threshold and reports low quality as a warning. Do not interpret a positive determinant as proof of good conditioning: a very flat tetrahedron can have positive volume and still be numerically poor.

5. Face extraction as a topological incidence problem

For every supported 3D element, the topology module enumerates local face templates. A face key is built by sorting its node indices, so two neighboring volume elements can match the same geometric face even when their local face order differs. The stored face retains an ordered node list for geometric use.

Number of incident volume elementsClassificationInterpretation
1BoundaryExposed face on the exterior of the volume mesh.
2InternalShared face between two volume elements.
More than 2Non-manifoldInvalid or non-manifold volume incidence for an ordinary 3D partition.

This is a combinatorial classification; it does not depend on a rendered surface or on proximity in floating-point space. Explicit dimension-2 surface elements are linked to derived volume faces by matching their node sets. Their physical-group names are then associated with the corresponding faces.

6. Edge incidence and boundary closure

Unique edges are built from face edges using a canonical endpoint pair (lower index first), while higher-order edge nodes are retained in order. On the extracted boundary surface, an edge incident to exactly two boundary faces is ordinarily part of a closed manifold surface. One incident boundary face indicates an open boundary edge; more than two indicates a non-manifold edge. These counts help detect holes and inconsistent surface topology, but do not establish geometric watertightness under every possible degeneracy.

7. Orientation consistency

Adjacent elements should traverse a shared face in opposite cyclic directions under a consistent orientation convention. If the same cyclic orientation is detected on both sides, OpenModel reports an orientation conflict. This is a warning about connectivity ordering; it is not a global proof that all elements form an orientable manifold.

8. Higher-order elements

Quadratic and higher-order elements add nodes along edges and, for some faces, in the face interior. Their connectivity stores corner nodes first, followed by midside nodes in the expected perimeter order and optional face nodes. Face identity must include the complete face node set to distinguish a curved high-order face from a linear face sharing only its corners. The viewer currently draws only corner nodes for higher-order elements; the full higher-order connectivity remains relevant to the mesh and topology layers.

9. What validation does not prove

Geometric validation checks implemented degeneracy, orientation and selected quality conditions. It does not certify convergence, element formulation suitability, material-model validity, boundary-condition adequacy, solver stability, or the physical correctness of an analysis. Those require engineering judgment, verification cases and comparison with independent results.
