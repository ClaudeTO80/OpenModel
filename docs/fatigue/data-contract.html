FEM result-source contract

Fatigue calculations begin with trustworthy result samples. A request identifies one exact field, one exact external entity and one exact solver step.

Solver-neutral boundary

IResultSource exposes source metadata, ordered steps and readSample(fieldName, position, stepIndex, out). It does not parse CalculiX, Code_Aster, Abaqus or other solver files. Importers populate OpenModel result models; adapters expose those models. No location fallback, interpolation, extrapolation or averaging is permitted by the source contract.

Physical-time semantics

Each step declares Time, Frequency, LoadFactor, None or User. A fatigue history accepts only explicitly time-valued steps, finite and strictly increasing in source order:

\[t_0<t_1<\cdots<t_{m-1},\qquad t_k\in\mathbb{R},\quad |t_k|<\infty.\]

Frequency/mode values and load factors are not silently interpreted as time. The builder does not sort samples or merge duplicate timestamps.

Field semantics and labels

Every sample carries quantity, component shape, component labels, frame, shear convention, unit, optional coordinate transform and provenance flags. Input component order is retained; there is no universal Voigt order. A six-value vector is not presumed to be a symmetric tensor. Labels must explicitly map to \(xx,yy,zz,xy,xz,yz\); duplicates, missing or unknown components are rejected.

Dimensions and units

\[[\sigma]=ML^{-1}T^{-2},\qquad [F]=MLT^{-2},\qquad [u]=L,\qquad [\varepsilon]=1.\]

PhysicalUnit includes symbol, scale-to-SI and optional affine offset. A known dimension does not imply a known scale. Zero scale means “not supplied”. CalculiX FRD/DAT do not declare a coherent unit system; the importer can identify quantity dimensions while leaving unit symbol and scale unknown.

No component silently assumes SI, converts MPa to Pa or reconciles inconsistent unit labels. Curves and samples must match exactly where required. Establish a consistent unit system before analysis.

Provenance and preparation policy

FatigueSamplePreparer retains the raw sample and applies policy. Averaged, interpolated and extrapolated samples are rejected by default; derived values are allowed by default. The caller can explicitly relax these rules. A false provenance flag means “not reported”, not proof that the operation never happened.

Lifetime

The adapter is non-owning: its FemResults must outlive it and must not be mutated concurrently. Independent readers can share an immutable result model.

ResultPosition ip;
ip.location = ResultLocation::IntegrationPoint;
ip.entityId = 1204;        // external element ID
ip.integrationPoint = 3;   // 1-based solver IP

auto built = StressHistoryBuilder::build(
    source, "STRESS", ip, ReferenceFrame::Global);
if (!built) { /* inspect status and diagnostic */ }
