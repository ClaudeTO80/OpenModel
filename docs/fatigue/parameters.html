Execution parameters and status codes

Every tunable input of the fatigue module with its type, unit, default, valid range and effect, followed by the status codes each stage can return. Values shown as defaults are those of the C++ structs; nothing is read from a configuration file.

Units. The module never converts units. A PhysicalUnit (dimension, symbol, scaleToSI, offsetToSI) attached to the data must match the unit of the material curve exactly (same symbol and scale), otherwise the stage returns IncompatibleUnit. Temperatures are always absolute (kelvin).

1. Source preparation: FatiguePreparationOptions

Policies applied by FatigueSamplePreparer to the provenance recorded with each FEM sample (see the data contract).

FieldDefaultMeaningWhen to change
allowAveragedfalseAccept values averaged across elements/nodes by the solver.Averaged nodal stress smooths peaks at discontinuities; enable only for smooth fields, and expect non-conservative results at notches.
allowDerivedtrueAccept values derived by the solver from other fields.Disable for strict audit trails.
allowInterpolatedfalseAccept interpolated values (e.g. integration point → node).Normally keep false: fatigue hot spots should come from the native location.
allowExtrapolatedfalseAccept extrapolated values (e.g. integration point → surface).Extrapolation can overshoot at the surface; enable consciously.

A required strength that is zero or negative yields MissingMaterialProperty; a mean at or beyond the strength yields OutsideMaterialStrength (or NonPositiveDenominator for Gerber); SWT with \(\sigma_{\max}\le0\) yields NonTensileMaximumStress.

5. Strain-life run (StrainLifeAnalysis::run)

ParameterDefaultValid rangeEffect
cyclicMaterial.youngsModulus \(E\)—> 0, stress unitElastic slope and CMB elastic term.
cyclicMaterial.cyclicStrengthCoefficient \(K'\)—> 0Ramberg–Osgood strength coefficient.
cyclicMaterial.cyclicStrainHardeningExponent \(n'\)—\(0<n'\le1\)Typical metals: 0.1–0.2. Very small \(n'\) makes the plastic term very steep; the solver works in logarithms to remain stable (see numerics).

correctionMethodNeuberNeuber, GlinkaLocal elastic–plastic conversion.
temperatureKelvin293.15—Recorded in the result; the constants themselves are for a single condition and are not temperature interpolated.
minimumReversals1> 0Lower end of the life search interval, in reversals \(2N_f\). A cycle needing less is reported as outside the interval.
maximumReversals\(10^{16}\)> minimumUpper end. A cycle whose damage parameter is below the value at this life (a run-out) is also reported as outside the interval. Widen it, or filter such cycles, if run-out cycles should simply contribute zero.
Run-out cycles. The strain-life models return CurveEvaluationFailed for any cycle whose life is outside \([2N_{\min},2N_{\max}]\); they do not silently discard it. The accepted strain parameter range is therefore \([f(2N_{\max}),\,f(2N_{\min})]\), where \(f\) is the life relation of the model.

Partial failure policy. In multi-position reports, a failing position does not abort the others: the report status is PartialFailure and each failed row carries its own status and diagnostic. Only if every position fails is the status AllPositionsFailed. Aggregate quantities such as the maximum damage consider successful positions only; check successfulPositions against the number requested before trusting a maximum.
