Stress-life fatigue (S–N)

Counted stress ranges are converted to amplitudes, optionally corrected for mean stress, evaluated against a tabulated S–N curve and accumulated with Palmgren–Miner.

S–N curve interpolation

Each point stores stress amplitude \(\sigma_a\) and cycles to failure \(N\). Within one temperature slice, interpolation is linear in log–log space:

\[\log_{10}N(\sigma_a)=\log_{10}N_1+ \frac{\log_{10}\sigma_a-\log_{10}\sigma_1}{\log_{10}\sigma_2-\log_{10}\sigma_1} (\log_{10}N_2-\log_{10}N_1).\]

For bracketing temperatures \(T_1,T_2\), log-life is interpolated linearly in kelvin:

\[\log_{10}N(\sigma_a,T)=(1-\eta)\log_{10}N(\sigma_a,T_1)+\eta\log_{10}N(\sigma_a,T_2),\quad \eta=\frac{T-T_1}{T_2-T_1}.\]

Amplitude must lie in the intersection of bracketing slices. Temperature and amplitude extrapolation are disabled. Each slice requires increasing amplitude and strictly decreasing life.

Range and amplitude

\[\sigma_a=\frac{\Delta\sigma}{2},\qquad \sigma_m=\frac{\sigma_{\max}+\sigma_{\min}}{2}.\]

Rainflow returns peak-to-peak range. Zero-range cycles contribute zero damage. Mean stress is retained for correction.

Mean-stress corrections

Let \(\sigma_{\max}=\sigma_m+\sigma_a\), ultimate tensile strength \(S_u\), yield strength \(S_y\) and true fracture strength \(S_f\).

MethodCorrected amplitudeStrength
Goodman\(\displaystyle \sigma_{a,c}=\frac{\sigma_a}{1-\sigma_m/S_u}\)\(S_u\)
Gerber\(\displaystyle \sigma_{a,c}=\frac{\sigma_a}{1-(\sigma_m/S_u)^2}\)\(S_u\)
Soderberg\(\displaystyle \sigma_{a,c}=\frac{\sigma_a}{1-\sigma_m/S_y}\)\(S_y\)
Morrow (S–N transform)\(\displaystyle \sigma_{a,c}=\frac{\sigma_a}{1-\sigma_m/S_f}\)\(S_f\)
SWT (stress-life equivalent)\(\displaystyle \sigma_{a,c}=\sqrt{\sigma_a\sigma_{\max}}\)\(\sigma_{\max}>0\)

Compression is retained algebraically; no tension-only clipping is applied. Goodman, Soderberg and Morrow reject mean stress at or above the reference strength. Gerber rejects a non-positive denominator. Missing strengths are errors.

SWT distinction: this S–N equivalent-amplitude transform is not the original strain-life SWT model \(P_{\mathrm{SWT}}=\sigma_{\max}\varepsilon_a\).
Applicability, the compressive-mean caveat and a numeric comparison of the five corrections are in Methods §4; a complete worked example is in Numerics §3. An amplitude outside the tabulated range is a failure, not an infinite life (Methods §3).

Palmgren–Miner damage

\[\Delta D_i=\frac{n_i}{N_i},\qquad D=\sum_{i=1}^{r}\frac{n_i}{N_i}.\]

Here \(n_i\) is the Rainflow count weight and \(N_i\) is life at corrected amplitude and selected temperature. Nominal repetitions of the block to \(D=1\):

\[L_{\mathrm{block}}=\begin{cases}1/D,&D>0,\\+\infty,&D=0.\end{cases}\]

Kahan compensated summation is used. No sequence effects, residual strength, statistical scatter or safety factors are included.

API and load spectra

PalmgrenMiner::evaluate accepts an explicit correction selector and strengths; default is None. The higher-level FatigueAnalysis::run currently constructs the damage input with that default, so choose a correction through the damage-model API unless orchestration is extended.

\[D_{\mathrm{spectrum}}=\sum_{b=1}^{B}r_bD_b,\qquad L_{\mathrm{spectrum}}=\begin{cases}1/D_{\mathrm{spectrum}},&D_{\mathrm{spectrum}}>0,\\+\infty,&D_{\mathrm{spectrum}}=0.\end{cases}\]

Each block is an independent history; its time can restart at zero. Input order is preserved for traceability, but linear Miner accumulation is commutative and has no sequence interaction.
