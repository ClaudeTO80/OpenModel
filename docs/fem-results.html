FEM results and tensor mathematics

Import solver output, bind it safely to a mesh, derive tensor invariants and visualize displacement or vibration modes.

Results are separate from the mesh

FemResults stores steps, named fields, component labels, external node/element IDs, and optional model coordinates. A field is either nodal or per-element. Keeping results independent of MeshData allows multiple result sets to refer to the same mesh and avoids polluting the mesh with solver-specific output.

Supported result sources

SourceCurrent support
CalculiX ASCII .frdNodal blocks, multiple steps/increments, displacement and tensor/scalar fields; coordinates used for mesh consistency checking.
CalculiX text .datNodal print blocks, element print blocks, and eigenvalue tables. Element integration-point rows are reduced to a per-element arithmetic mean with a diagnostic.
CSV/TSV/TXTNodal or per-element tabular values, one row per entity; scalar, vector and recognized six-component tensor columns.

Binary FRD, Abaqus ODB/FIL, Nastran OP2, Exodus, VTK/VTU and ANSYS result files are not supported by the current readers. Integration-point result fields from FRD are not silently converted.

Binding: identity before visualization

bindResults maps records by external node or element ID. For formats carrying coordinates (FRD), shared node coordinates are compared to the mesh. The default tolerance is 2e-5 × max(bounding-box diagonal, largest absolute coordinate), chosen to tolerate the printed precision documented for CalculiX. A mismatch rate above 1% is an error; a smaller mismatch rate is a warning. CSV has no coordinates, so only IDs can be checked.

Matching IDs alone cannot prove two meshes are geometrically identical. For formats without coordinates, the importer can detect missing/unmatched IDs but cannot independently establish geometric equivalence.

Vector fields

For a three-component vector u = (ux,uy,uz), the magnitude field is

\[\|\mathbf{u}\|=\sqrt{u_x^2+u_y^2+u_z^2}.\]

The displacement vector can also be used to deform the displayed geometry by a visualization scale factor α:

\[\mathbf{x}_{\mathrm{display}}=\mathbf{x}_{\mathrm{mesh}}+\alpha\mathbf{u}.\]

The scale factor changes the picture only; it does not change the stored solution or the physical displacement.

Symmetric stress tensor

OpenModel recognizes six-component symmetric tensors in the order XX, YY, ZZ, XY, YZ, ZX (with solver-specific prefixes such as SXX). They form

\[\boldsymbol{\sigma}= \begin{bmatrix} \sigma_{xx}&\sigma_{xy}&\sigma_{zx}\\ \sigma_{xy}&\sigma_{yy}&\sigma_{yz}\\ \sigma_{zx}&\sigma_{yz}&\sigma_{zz} \end{bmatrix}.\]

Principal stresses are the eigenvalues σ₁ ≥ σ₂ ≥ σ₃ of this real symmetric matrix. They are invariant under orthogonal rotation of the coordinate basis. The implementation obtains them with cyclic Jacobi rotations, a numerically robust iterative diagonalization for symmetric 3×3 matrices.

Hydrostatic and deviatoric stress

\[\sigma_m=\frac{\operatorname{tr}(\boldsymbol{\sigma})}{3} =\frac{\sigma_{xx}+\sigma_{yy}+\sigma_{zz}}{3}, \qquad \mathbf{s}=\boldsymbol{\sigma}-\sigma_m\mathbf{I}.\]

The von Mises equivalent stress is

\[\sigma_{\mathrm{VM}}= \sqrt{\frac{1}{2}\left[ (\sigma_{xx}-\sigma_{yy})^2+ (\sigma_{yy}-\sigma_{zz})^2+ (\sigma_{zz}-\sigma_{xx})^2 \right]+3(\tau_{xy}^2+\tau_{yz}^2+\tau_{zx}^2)}.\]

The Tresca scalar is σ₁−σ₃. These are scalar summaries, not substitutes for the full tensor. Von Mises is commonly used for isotropic ductile yielding; Tresca corresponds to a maximum-shear criterion.

Strain tensor and shear convention

For small-strain kinematics, ε = ½(∇u + ∇uᵀ). Its six independent components use tensor shear strains εxy, εyz, εzx. Engineering shear is γxy = 2εxy. The binding option engineeringShearStrain halves engineering shear inputs before calculating invariants; CalculiX output is documented here as tensor shear, so the default is false.

The deviatoric strain is e = ε − tr(ε)I/3. OpenModel's equivalent strain is

\[\varepsilon_{\mathrm{eq}}= \sqrt{\frac{2}{3}\,\mathbf{e}:\mathbf{e}} = \sqrt{\frac{2}{3}\left[ (\varepsilon_{xx}-\varepsilon_m)^2+ (\varepsilon_{yy}-\varepsilon_m)^2+ (\varepsilon_{zz}-\varepsilon_m)^2+ 2(\varepsilon_{xy}^2+\varepsilon_{yz}^2+\varepsilon_{zx}^2) \right]}.\]

Volumetric strain in the small-strain approximation is tr(ε); the maximum engineering shear strain is ε₁−ε₃.

Element results and integration points

Per-element fields are matched by element ID and rendered as a constant value on the triangles belonging to that element. They are not spatially interpolated across an element. For CalculiX DAT element print blocks, values from integration points are currently reduced by an unweighted arithmetic mean. This is exact only in special equal-weight/single-point cases; for unequal Gauss weights it is an approximation. The implementation emits DAT_IP_AVERAGED. It does not claim to reconstruct a continuous stress field or extrapolate integration-point values to nodes.

Missing data and modal analysis

Missing records are represented as NaN during binding. Missing nodes/elements are filled with that field's minimum for display so they do not expand the colour range; the count is reported in diagnostics. Frequency steps are treated as vibration modes. Eigenvalue tables alone contain frequencies but not mode shapes, so a field-bearing result file (normally FRD) is required for modal deformation. By default, up to 20 modes can be bound when the file consists entirely of modes.

Interpretation cautions

  • Derived invariants are computed from values at nodes or per-element records, not directly at integration points.
  • Stress and strain are assumed to be in global axes; there is no local-coordinate transformation.
  • Only corner nodes of higher-order elements are currently drawn by the viewer.
  • Result import tests do not replace validation against complete files from each supported solver version.
