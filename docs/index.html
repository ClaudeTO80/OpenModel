What is OpenModel?

OpenModel is a C++17 library, command-line application and optional lightweight desktop workbench for finite-element meshes and results. Its central workflow is to import CAD or an existing mesh, generate and validate a discretization, prepare solver input, execute CalculiX where supported, import result files and inspect fields in a WebGL viewer.

The core deliberately separates the mesh representation (MeshData) from analysis settings (AnalysisModel) and solver output (FemResults). This separation allows one mesh to be reused with different analysis definitions and result sets without embedding solver-specific state in the mesh.

Capabilities at a glance

AreaCurrent implementation
Mesh coreLinear and quadratic point, line, surface and volume element types; blocks; node sets; physical groups.
Topology and validationDerived faces/edges, boundary and internal classification, non-manifold diagnostics, geometric checks and tetrahedron quality.
InterchangeAbaqus/CalculiX .inp subset; native MGMB binary mesh; glTF/GLB and MGWV viewer export.
Optional geometry/meshingOpen CASCADE, Gmsh, TetGen, Netgen, MFEM and Assimp adapters.
ResultsCalculiX ASCII FRD, DAT and nodal/per-element delimited tables; derived stress/strain fields and modal visualization.
AnalysisLinear elastic, one-material, single-step static or frequency input generation for CalculiX.

Important engineering boundary

OpenModel is a pre/post-processing and workflow tool, not an independent finite-element solver. The current solver-input path targets a restricted CalculiX workflow. The repository README explicitly states that generated input has not yet been validated by a real CalculiX run in the latest test environment; automated solver tests use a stand-in and verify plumbing, not physical correctness.

How to use this manual

Start with Getting started to build the project. Read Mesh data model before writing importers or adapters. Use Mathematical foundations to understand the geometric predicates and quality measures. The FEM results and Analysis workflow chapters explain the result and solver pipelines.
