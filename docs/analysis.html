Analysis setup and CalculiX workflow

Define a restricted linear-elastic analysis, understand the generated input and interpret the assumptions behind loads and modal steps.

Separation of mesh and analysis

The mesh does not own materials, supports, loads or solution steps. These are represented by AnalysisModel, created in code or parsed from a compact analysis script. writeSolverInput combines the mesh and analysis definition into a CalculiX .inp file.

Analysis script

material E=210000 nu=0.3 rho=7.85e-9 name=STEEL
fix plane:x=0 dof=1,2,3 tol=1e-6
force plane:x=10 F=0,-100,0
pressure group:Top p=2.5
gravity g=0,0,-9810
step static
output element=auto

Commands are one per line; # starts a comment. Selectors are all, group:NAME and coordinate planes plane:x=VALUE (also y and z). Plane selection uses a tolerance, defaulting to 10⁻⁶ times the model diagonal.

Linear isotropic elasticity: mathematical model

The current material model is defined by Young's modulus E and Poisson's ratio ν (and density ρ when required). For small displacement gradients, the infinitesimal strain tensor is

ε(u) = ½(∇u + ∇uᵀ).

For homogeneous isotropic linear elasticity, the Cauchy stress is related to strain by Hooke's law

σ = 2μ ε + λ tr(ε) I,   μ = E/[2(1+ν)],   λ = Eν/[(1+ν)(1−2ν)].

This is a small-strain, linear, isotropic constitutive law. It is not a plasticity, hyperelasticity, damage, contact or temperature-dependent material model. The generated solver input currently applies one material to all volume blocks.

Weak form and finite-element discretization

In static equilibrium without inertia, the strong form is ∇·σ + b = 0 in Ω, with prescribed displacement u = ū on Γu and traction σn = t̄ on Γt. Multiplying by a virtual displacement δu, integrating over Ω and applying the divergence theorem gives the weak statement

∫Ω ε(δu):σ(u) dΩ = ∫Ω δu·b dΩ + ∫Γt δu·t̄ dΓ.

After interpolation u ≈ N d, the element stiffness has the familiar form

Ke = ∫Ωe Bᵀ D B dΩ,   Kd = f.

Here N contains shape functions, B maps nodal degrees of freedom to strain, and D is the constitutive matrix. OpenModel does not assemble or solve this system itself; it writes a solver deck for CalculiX. The equations explain the physical model expected by that solver and the meaning of the input data.

Supports and loads

Essential boundary conditions

fix constrains selected translational degrees of freedom at nodes. In the weak formulation, prescribed displacement removes the corresponding virtual variations from the admissible test space. A static structure must be sufficiently constrained to remove rigid-body modes; OpenModel checks for the presence of supports, but does not prove that their placement makes the model stable.

Nodal force distribution

force represents a total vector F shared equally across n selected nodes:

Fi = F/n,   i = 1,…,n.

This is a simple lumped distribution, not the consistent finite-element load vector obtained by integrating shape functions over a loaded boundary. For quadratic elements it is not generally consistent; the project warns about this limitation. Prefer pressure for a distributed surface load when the supported face topology permits it.

Surface pressure

pressure acts on a named dimension-2 physical group. OpenModel checks that each selected surface element corresponds to a boundary face of exactly one supported volume element, then maps the face to the appropriate CalculiX face label. Positive pressure is defined as acting into the body (compressive). A pressure load is conceptually a traction field integrated over the surface, yielding equivalent nodal forces through the solver's element formulation.

Gravity

Gravity is an acceleration vector g and requires density. The corresponding body-force density is b = ρg. Units must be internally consistent: OpenModel does not infer or convert units.

Static and frequency steps

A static step solves equilibrium under the specified loads. A frequency step requests eigenfrequencies and mode shapes. In the linear undamped setting, the free-vibration problem is

(K − ω²M)φ = 0,   det(K − ω²M) = 0.

ω is circular frequency, M is the mass matrix, and φ is a mode shape. The associated frequency in cycles per unit time is f = ω/(2π). Negative eigenvalues may indicate instability or an unconstrained/ill-posed model; interpretation depends on solver conventions and the model.

Generated solver deck and execution

The writer emits volume elements, material/elastic/density definitions, solid sections, boundary conditions, static loads or frequency extraction, and result requests. Surface and line elements in the mesh describe boundaries; they are not written as structural volume elements. The CLI can write input separately or launch ccx in a work directory. On successful execution it can export viewer data and load the associated result files.

Current scope and verification

One material, one analysis step, small-strain linear elasticity, static or frequency analysis, no contact and no nonlinear material behavior. Pressure support is limited to tetrahedral/hexahedral volume faces. The force distribution is equal nodal sharing. ProcessRunner is POSIX-only. The repository README and solver guide state that the generated input has not yet been checked by a real CalculiX run in the latest environment; test fixtures use a fake solver and do not verify physics.
