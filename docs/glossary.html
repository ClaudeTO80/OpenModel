Glossary and symbol index

An alphabetical guide to the principal OpenModel concepts and a compact index of the mathematical notation used throughout this manual.

Term index

TermMeaningSee also
Boundary faceDerived volume face incident to exactly one volume element.Mesh mathematics
CADComputer-aided design geometry, optionally imported through Open CASCADE.CAD & meshing
Conformal meshAdjacent components share interface nodes and a matching interface discretization.CAD & meshing
Element blockCollection of elements sharing one topology and nodes-per-element count.Mesh data model
External IDStable source node or element identifier, distinct from an internal zero-based index.Mesh data model
Finite elementA cell of the discretized domain on which an approximation/interpolation is defined.Mesh mathematics
Integration pointQuadrature point used by a finite-element solver to evaluate element integrals.FEM results
JacobianDerivative matrix of the mapping from reference element coordinates to physical coordinates.Mesh mathematics
Mean-ratio qualityNormalized tetrahedron shape metric whose ideal regular-tetrahedron value is 1.Mesh mathematics
MGMBOpenModel's native, versioned binary mesh persistence format.File formats
MGWVOpenModel's render-oriented binary container for the WebGL viewer.File formats
Physical groupNamed collection of elements with a topological dimension and tag.Mesh data model
Principal stressEigenvalue of the symmetric Cauchy stress tensor.FEM results
Result bindingMapping of result records onto mesh entities by external IDs, with optional coordinate checks.FEM results
Shape functionInterpolation basis function mapping nodal degrees of freedom into a field inside an element.Analysis workflow
Topological faceCombinatorial face identified by the node connectivity of adjacent volume elements.Mesh mathematics
Von Mises stressScalar equivalent stress based on the second invariant of the deviatoric stress tensor.FEM results
