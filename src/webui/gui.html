OpenModel Workbench

CAD → FEM mesh → visualization

1 · CAD geometry

2 · CAD tessellation

Sets the surface shown before meshing and, for TetGen, the surface that gets filled.

3 · Volume meshing

The mesh is always structured. Hexahedral blocks (six four-sided faces) get transfinite curves, surfaces and volume; straight prisms (beams, bars, cylinders, profiles) are swept in layers. The number of divisions follows the maximum element size. A solid that is neither is reported and not meshed.

Above Error the log is also saved as _gmsh.log next to the CAD file; Info adds the phase timings, Debug the internal Gmsh messages.

4 · Mesh files

5 · FEM results

Values are mapped to the nodes of the current mesh by node number; a file that does not belong to the mesh is rejected. Fields and the deformed shape appear in the viewer.

6 · Analysis and solver

    Edit or remove individual materials, constraints, loads and steps. Changes update the script used by the solver directly.

      Read-only: names/layers from the CAD file. The dimension identifies vertex (0), edge (1), face (2) or solid (3).

      The group stores the IDs of the selected B-Rep faces and is saved next to the CAD file in the .omgroups sidecar. Gmsh, TetGen and Netgen can transfer it to the FEM mesh: the Node Set NAME_NODES is created. TetGen requires the face IDs in the CAD tessellation; Netgen uses geometric mapping. After meshing, the 'Fix' button inserts the zero-displacement constraint into the script. Group changes invalidate the generated volume mesh, which must then be regenerated.
