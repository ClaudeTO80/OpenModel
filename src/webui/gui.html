Geometry
Tessellation

Sets the surface shown before meshing and, for TetGen, the surface that gets filled.

Named groups from the CAD file

    Read-only: names/layers from the CAD file. The dimension identifies vertex (0), edge (1), face (2) or solid (3).

    CAD face groups

    The group stores the IDs of the selected B-Rep faces and is saved next to the CAD file in the .omgroups sidecar. Gmsh, TetGen and Netgen can transfer it to the FEM mesh: the Node Set NAME_NODES is created. TetGen requires the face IDs in the CAD tessellation; Netgen uses geometric mapping. After meshing, the 'Fix' button inserts the zero-displacement constraint into the script. Group changes invalidate the generated volume mesh, which must then be regenerated.

      Volume meshing

      The mesh is always structured. Hexahedral blocks (six four-sided faces) get transfinite curves, surfaces and volume; straight prisms (beams, bars, cylinders, profiles) are swept in layers. The number of divisions follows the maximum element size. A solid that is neither is reported and not meshed.

      Limits the element size at the corners of thin faces (width times this factor). On a plate with thin side strips, 1 is a good start.

      Off by default: on the models tested, it gave no clear gain over the default sizing and increased the meshing time a lot. Try it only when a non-planar face is badly meshed.

      One entry per top-level body of the CAD file, in the order they are imported. Empty = every body in the global dimension. A volume body is exported with its volume elements only; a surface body with its surface elements.

      Tetrahedra (Gmsh) settings

      The defaults are Gmsh's own. Use the minimum element size and the curvature points to refine curved faces; the 2D and 3D algorithms and the optimisation change the element quality.

      Above Error the log is also saved as _gmsh.log next to the CAD file; Info adds the phase timings, Debug the internal Gmsh messages.

          Known materials

          Choose a material to fill the form below.

          Edit material

          Saving writes the material to the materials file at once. Built-in materials cannot be changed: save a copy with another identifier. Set in script writes the values of the form as the material line of the script, with the identifier as its name; the first material line of the script is the default material; further materials are added with an id= and assigned to parts below. All values must be in the units of the script.

          Material in the script
            Assign to group

            Select a group in the tree (Material or Mesh > Groups).

            Gives the material chosen here to the group selected in the tree. The choice is written to the script as an assign line with the group name.

            Material per part

            Each volume part of the mesh takes the default material unless another one is chosen here. The choice is written to the script as an assign line.

              Mesh constraints (stored in the mesh)

              Select a face (mode Faces: the connected faces with the same normal, or the wall of a hole, are selected together), tick the degrees of freedom to block and press Apply: they are blocked on every node of the selection, mid-side nodes included. The constraints are drawn in the viewer and written to the solver input. Rotations are stored and drawn, but the solver ignores them on solid elements.

                Script constraints (fix)

                Creates a node group from the selection and appends the fix line to the script.

                  Loads and steps

                  Force acts on the selected nodes, pressure on the selected faces. Each assignment appends the line to the script. A load with an amplitude is multiplied by the factor of that amplitude at the time of the step.

                    Time dependence
                      Step

                      Replaces the step line of the script. A dynamic analysis needs the density (rho=) and supports (fix). Loads without amplitude act at full value from the start.

                      Analysis and solver

                      Edit or remove individual materials, constraints, loads and steps. Changes update the script used by the solver directly.

                      Commands: material E= nu= rho=, fix plane:x=0 [dof=1,2,3], force plane:x=10 F=fx,fy,fz, pressure group:NAME p=, gravity g=gx,gy,gz, step static or step frequency modes=N. Selectors: all, group:NAME, plane:x|y|z=VALUE. Use consistent units of your choice. When the run finishes, the results are loaded automatically.

                      Results

                      Values are mapped to the nodes of the current mesh by node number; a file that does not belong to the mesh is rejected. Fields and the deformed shape appear in the viewer.
